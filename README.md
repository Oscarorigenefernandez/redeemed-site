# Redeemed storefront

A responsive black-and-gold Christian streetwear storefront built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and sections
- `styles.css` — responsive black-and-gold visual design
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Connect products
The Apparel cards are currently design placeholders. Replace them with your real Fourthwall product photos, names, prices, and product-page checkout URLs before launch. Do not add payment credentials or secret API keys to this public frontend.

## Domain
When the GitHub Pages site is ready, configure `redeemedappreal.com` under Settings → Pages → Custom domain and update the domain's DNS records as GitHub instructs. Confirm whether the domain is currently attached to Fourthwall before changing DNS.
